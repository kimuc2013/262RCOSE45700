캐시 재사용 진단

계측 추가 이후의 요청만 집계합니다. 조건이 맞는 후보 없음, 유사도 미달, 서명 인식 실패를 구분합니다. 임베딩 캐시 분모는 실제 조회가 관측된 요청입니다.

실제 API 작업과 보고된 토큰

미제공 usage는 미확인입니다. 다른 모델의 토큰을 비용으로 합산하지 않습니다. 공급자 캐시 토큰은 입력의 일부이며 추가 소비로 더하지 않습니다.
차트는 선택 기간의 60개 구간입니다. 빈 지연 구간과 미확인 토큰 구간은 선을 잇지 않습니다. 응답 캐시와 검색 순위 재사용은 별도 표시합니다. 캐시·공유율 차트의 분모는 각 구간의 검색·답변 도구 전체 호출(실패 포함)입니다. API 이벤트는 작업 완료 시 기록되어 늦게 반영될 수 있습니다. 지표 조회는 학사 요청 수에 포함되지 않습니다. 토큰은 우리 서버 API만 관측하며 외부 ChatGPT 사용량과 GPT 대비 절감률은 알 수 없습니다.
