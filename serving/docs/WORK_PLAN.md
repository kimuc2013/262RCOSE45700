다음 순서:

1. 팀과 모델 API 계약을 확정하고 모델별 요청 1건을 검증합니다.
2. robots.txt, 출처, 개인정보 정제 정책을 확인하면서 크롤러를 학부 공통 페이지로 확장합니다. 현재 샘플은 자동으로 재수집하지 않았습니다.
3. 원문에서 정답과 근거를 작성한 고정 질문셋으로 BM25, 하이브리드 검색, 리랭킹을 비교하고 임계값을 보정합니다.
4. 그 결과를 바탕으로 의미 캐시와 단계 생략을 도입하고 오반환을 측정합니다.
5. AWS가 준비되면 동일 컨테이너를 옮기고 S3, HTTPS, 클라이언트 연결을 확인합니다.

2GB EC2에서 충분하다는 실측 근거는 아직 없습니다. 전체 색인 크기, 프로세스 RSS, 동시 요청 시 지연을 확인한 뒤 사양을 확정합니다. 기존 기획 목표를 실제 측정값으로 바꾸지 않습니다.
